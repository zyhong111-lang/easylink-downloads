# EasyLink Downloads

Official direct-download release repository for EasyLink on macOS and Windows.

This repository contains installers, updater packages, public verification keys, checksums and release notes. It contains no private signing keys, member data, server credentials or source-worktree archives.

## Update channels

- Stable releases: versioned release assets and the `updater/update.json` manifest.
- Existing downloads using the former update server require one manual installation of the migration release. Subsequent updates use this repository. The old release repository is read-only to the current publisher.
- Mac App Store and Microsoft Store editions continue to use their store update channels.

Release assets are made available only after build and update-signature verification. See each release for platform signing/notarization status and installation instructions.
